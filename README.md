### Kernel Subsystems & Active Focus

* **Process Concurrency & Protocols:** Inter-process communication (IPC), local WebSocket pipes, browser instrumentation, Model Context Protocol (MCP) implementations, and runtime isolation.
* **Data Systems & Ingestion:** Relational modeling on PostgreSQL, structured data transformations, statistical analysis, and public domain API ingestion (OpenFDA, open governance).
* **Distributed & Edge Infrastructure:** Serverless micro-services with Cloudflare Workers, event-driven architectures, and automated continuous delivery with GitHub Actions.
